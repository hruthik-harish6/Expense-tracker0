# Run this project first

1. Open this folder in VS Code.
2. Open Terminal.
3. Run:

```powershell
py -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

4. Open http://127.0.0.1:5000
5. Create an account.
6. Add your own transaction.
7. Try Transactions, Budgets, Insights, Settings and Export.

The app starts with **zero** fake money. Your account owns its own transactions.
